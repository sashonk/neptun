## Текущая цель уровня

Подобрать **ключ**, затем дойти до **exit** (дверь). Смерть → рестарт того же seed (3 бомбы снова); exit с ключом → экран «уровень пройден» → следующий уровень.

---

## Цели уровня — приоритеты

### P1 — быстро, сильный эффект

- [x] **Ключ → дверь** — exit закрыт, пока не подобран ключ на карте
- [ ] **Убить всех големов** — exit открывается только когда врагов 0
- [ ] **Чеклист в HUD** — `☐ ключ ☐ големы ☐ exit`, игрок видит цель

### P2 — меняет тактику

- [ ] **Сбор осколков** — exit всегда доступен, но для бонуса/прогресса нужно N штук
- [x] **Лимит бомб** — 3 бомбы на уровень, кулдаун 3 сек, сброс при любом рестарте
- [ ] **Маяки на больших картах** — активировать 2–3 точки, подсветка направления к exit (150×150, 300×300)
- [ ] **Зоны / порталы** — на огромной карте цель уровня = следующая зона, не весь файл

### P3 — отложено

- Эскорт NPC до exit
- Защита точки N секунд (големы идут волной)
- Туман войны — exit известен после исследования N% клеток
- Hazard-тайлы — дойти до exit, не наступая на `physical_hazard`
- Ежедневный seed — сравнение времени/смертей
- Мета-прогрессия: апгрейды за осколки между уровнями

---

## Модель «уровня 2.0»

Один уровень = 2–3 условия, не все сразу:

```
Уровень N:
  • ключ (обязательно, с уровня ~5)
  • exit (обязательно)
  • бонус: все големы / осколки / без смерти
```

`seed` — где ключ и exit; `level` — сколько условий активно.
